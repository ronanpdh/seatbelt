# Working in this repository

Follow [CONTRIBUTING.md](CONTRIBUTING.md) and [STANDARDS.md](STANDARDS.md).

- **Branch names:** `feature/…`, `fix/…`, `chore/…` or `docs/…` for the kind of change, as CONTRIBUTING.md ("Changes") says. Never a generated name such as `claude/<words>`. If a session was given a generated branch, create one named this way from `main` and push that instead: the maintainer has asked for it.
