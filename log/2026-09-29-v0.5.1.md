# 0.5.1: a review of the whole project

Released 2026-09-29. Build notes: [docs/BUILD.md](../docs/BUILD.md#051-a-review-of-the-whole-project).

## What shipped

- Fixes from a review of the whole project, each checked by a second reader. There are no new commands.
- **Gateway.**
  - Probe routes are forwarded only for ids of the expected shape. Before, an authenticated employee could reach other provider endpoints through them with the gateway's provider key, unrecorded.
  - Request shapes it could not record faithfully are refused with 400.
  - Request bodies have size and depth limits.
- **Redaction** covers more secret formats and dict keys, and `Ledger.append` itself redacts every event's actor ids and `parent_id`.
- **Tamper evidence.** `verify-pack --pubkey` fails an unsigned pack. Pack reading is bounded. Without a key, `verify`, `verify-pack` and `report` compare a signature file with its ledger.
- **Terminal output** escapes control characters in recorded text.
- **Release workflow.** The build job never installs the dev dependencies, and the tests run in their own job.

## Plan vs what shipped

- There was no plan or design note for this release. The changelog opens with "A review of the whole project, with every finding checked by a second reader. Upgrade gateways promptly."
- It changes what earlier docs say. ADRs 0001, 0002 and 0007, the evidence pack spec and `docs/local-recording.md` were all updated.

## Worth studying

- The probe-route finding. A model lookup or a Code Assist operation read, forwarded without being recorded, let an authenticated employee reach other provider endpoints with the gateway's provider key (CHANGELOG 0.5.1, Security).
- Refusing what the gateway cannot record faithfully. Gemini fields in snake_case escaped the record, the output-token cap and the tool denylist (CHANGELOG 0.5.1, Security).
- A consistency check versus tamper evidence. Without a key, comparing a sidecar with its ledger "catches a careless edit only" ([ADR 0002](../docs/adr/0002-signed-run-manifest.md)).
- What a local signature proves when the agent runs as you: that the file has not changed since it was signed, by another user or a later accidental edit. It does not protect the run from the agent itself ([docs/local-recording.md](../docs/local-recording.md#limits)).
- Terminal escape injection: why recorded text is printed with control characters made visible (`src/seatbelt/terminal.py`).
- Keeping the release build away from the dev dependencies and the tests (`.github/workflows/release.yml`).
