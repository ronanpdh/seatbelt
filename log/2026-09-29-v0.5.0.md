# 0.5.0: on PyPI

Released 2026-09-29. Build notes: [docs/BUILD.md](../docs/BUILD.md#050-on-pypi).

## What shipped

- Releases are published to PyPI as `seatbelt-ai` through Trusted Publishing, with no stored token and with PyPI's attestations.
- The module and the command stay `seatbelt`.
- The provenance asset is renamed `seatbelt_ai-<version>.intoto.jsonl`.

## Plan vs what shipped

- The setup guide's first step was checking the name on PyPI. The PyPI design records that `seatbelt` is an unrelated project, uploaded 2026-04-13, which installs the same module and command.

## Worth studying

- Trusted Publishing: PyPI trusts the workflow's OIDC identity, so no password or token is stored anywhere ([PyPI design](../docs/plans/2026-09-29-pypi-design.md), P1 to P3).
- Why the distribution name and the import name can differ (`[tool.uv.build-backend] module-name`).
- Why two uv tools cannot both provide a `seatbelt` command: uv links every tool's executables into one shared directory.
- A required reviewer on the `pypi` environment, so each upload waits for the maintainer's approval.
