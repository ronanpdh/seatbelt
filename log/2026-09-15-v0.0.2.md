# 0.0.2: real agents through adapters

Released 2026-09-15. Build notes: [docs/BUILD.md](../docs/BUILD.md#002-real-agents-through-adapters).

## What shipped

- An Anthropic Messages API adapter. It records:
  - requests;
  - responses, with the model version the provider returned and the token usage;
  - `tool_use` blocks as `tool.call`, and matching `tool_result` blocks as `tool.result`.
- An OpenAI Agents SDK adapter, `SeatbeltProcessor`, built as a tracing processor.
- `Recorder.tool_called` and `Recorder.tool_returned`, for adapters that observe tool calls without executing them.
- Ledger schema version 1. 0.0.1 ledgers are rejected as an old format.
- `seatbelt verify` reports INCOMPLETE when the chain is intact but its end is missing.
- A release workflow: the wheel, sdist and a CycloneDX SBOM, with Sigstore-signed SLSA provenance and SBOM attestations.
- A recorded fixture and replay tests. The adapter tests skip when the extra is absent.

## Plan vs what shipped

- ADR-0008, the adapter boundary, was never written.
- The `Adapter` protocol shipped, and was removed in 0.0.3 because nothing consumed it.
- Signed releases arrived in 0.0.2. The setup guide had placed them in week 15.

## Worth studying

- Attribution from the provider. `response.model` is the version the provider served, which can differ from the alias you asked for. It lands in `Actor.version`. The adapters guide calls this "the single most important line for attribution" (step 4).
- Two shapes of adapter: a wrapper around a client you call (Anthropic), and a hook registered in a framework's own tracing system (OpenAI Agents SDK) (adapters guide, "What an adapter is, and is not").
- Replay, not live calls. Tests never touch a live model, because live tests "would be slow, cost money, need secrets in CI, and give different answers every run" (adapters guide, step 5).
- Ledger text is untrusted input. `seatbelt reconstruct` rendered ledger text as Rich markup, so ledger content could restyle or hide cells (CHANGELOG 0.0.2, Fixed). The same idea returns in 0.5.1's terminal escapes.
- Why a schema version: the canonical form is tied to the Pydantic model, so changing a field changes every hash ([ADR 0001](../docs/adr/0001-hash-chained-jsonl-ledger.md), Consequences).
