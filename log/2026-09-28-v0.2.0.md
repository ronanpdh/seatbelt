# 0.2.0: record an organisation through a gateway

Released 2026-09-28. Build notes: [docs/BUILD.md](../docs/BUILD.md#020-record-an-organisation-through-a-gateway).

## What shipped

- `seatbelt gateway serve`, an HTTP service that records every client pointed at it. It speaks Anthropic Messages and OpenAI Chat Completions, streamed or not.
- Per-employee issued keys, stored as SHA-256 hashes, and one signed ledger per employee session.
- Org policy: allowed models, an output-token cap, and denied tools.
- `seatbelt run claude`, which presets Claude Code's environment, and `seatbelt report`, usage across the fleet.
- A gateway Docker image and deployment docs, including Claude Desktop and Cowork through MDM.

## Plan vs what shipped

- The original build guide stopped at 0.1.0. This release came from its own design note, [2026-09-18-gateway-design.md](../docs/plans/2026-09-18-gateway-design.md).
- The design put a `codex` launcher preset in 0.2.0. It was refused until 0.3.0, because current Codex speaks only the OpenAI Responses API.

## Worth studying

- Why the gateway handles wire formats rather than models, one module per format ([ADR 0006](../docs/adr/0006-recording-gateway.md)).
- The gateway cannot stop a tool running on the employee's machine. So it records the denied call and refuses any later request that carries the tool's result ([ADR 0006](../docs/adr/0006-recording-gateway.md)).
- Why a session is never closed while a request holds it: no event may land after `run.end`.
- Why `principal.*` is set after any client-supplied metadata: so a client cannot overwrite it.
- Signals: the launcher starts ignoring Ctrl-C only after spawning the CLI, because an ignored signal is inherited ([ADR 0007](../docs/adr/0007-launcher.md)).
- SSE reassembly. A stream that breaks is recorded as far as it got, without tool calls whose inputs may be truncated.

## Reflection

> The gateway records a denied tool call but cannot stop it; it refuses the next step instead. Is that enough for the people you are building this for, and what would you tell them it does not cover?
