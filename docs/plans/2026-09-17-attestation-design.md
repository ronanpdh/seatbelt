# Attestation design (0.0.4)

Date: 2026-09-17. Status: agreed, not yet implemented.

## Problem

ADR 0001: any edit inside the chain is detected, but truncating the tail and rewriting `run.end` with a matching count passes `verify`. The final hash has to be recorded somewhere the ledger writer cannot rewrite.

## Decision

A signed manifest per run, written as a sidecar `<run_id>.attest.json` beside the ledger. Ed25519 via `cryptography`. Keys are PEM files generated by `seatbelt keygen`.

Rejected: HMAC (symmetric, verifier can forge), Sigstore keyless (network at sign time, heavy deps; revisit when cross-org trust is needed), inline `run.attest` event (schema bump, and a rewriter drops it like any tail).

## Manifest

```json
{
  "attest_version": 1,
  "run_id": "…",
  "schema_version": 1,
  "events": 42,
  "final_hash": "sha256 of the last event",
  "ledger_sha256": "sha256 of the ledger file bytes",
  "harness": "seatbelt 0.0.4",
  "signed_at": "2026-09-17T12:00:00Z",
  "public_key": "base64 raw 32-byte Ed25519 public key",
  "signature": "base64 Ed25519 over canonical JSON of every field except signature"
}
```

Pydantic model, `extra="forbid"`, canonical form as `Event` (sorted keys, compact). `final_hash` closes the truncation gap; `ledger_sha256` catches any byte change. `public_key` is informational: trust comes from the `--pubkey` file the verifier supplies, never from the embedded value.

## Module

`src/seatbelt/attest/`:

- `manifest.py`: `Manifest` model, `build(ledger_path) -> Manifest` (unsigned), `canonical()`.
- `sign.py`: `Signer` wrapping `Ed25519PrivateKey` with `generate()`, `from_file(path)`, `sign(manifest) -> Manifest`, `public_pem()`; `keygen(dir)` writes `seatbelt.key` (PKCS8 PEM, mode 0600) and `seatbelt.pub` (SubjectPublicKeyInfo PEM), refuses to overwrite.
- `AttestError` for bad key files and refused operations.

`src/seatbelt/verify/attest.py`: `verify_attestation(ledger_path, pubkey_path) -> AttestVerdict(status, reason)` with `Attestation` enum UNATTESTED/UNCHECKED/ATTESTED/FORGED. `chain.py` and its `Verdict` untouched; the CLI composes both.

## Flow

**Recorder.** `Recorder.start(..., signer: Signer | None = None)`. In the context manager's `finally`, after `run.end` is written: if a signer is set, build, sign and write the sidecar (mode 0600). A failed run is still signed; a signed failure is evidence. A signing error propagates; the ledger is already complete on disk.

**CLI.**

- `seatbelt keygen [dir]`
- `seatbelt attest <ledger> --key seatbelt.key`: verifies the chain first and refuses BROKEN; refuses an existing sidecar.
- `seatbelt verify <ledger> [--pubkey seatbelt.pub]`: chain check as today, then:
  - no sidecar: `UNATTESTED`, exit 1 if `--pubkey` was given, else unchanged; the key file is loaded either way so a typo fails
  - sidecar, no `--pubkey`: `UNCHECKED`, exit unchanged, warning
  - sidecar and pubkey: signature over the canonical form with the trusted key, then `run_id`, `schema_version`, `events`, `final_hash`, `ledger_sha256` against the ledger. All match: `ATTESTED`. Otherwise `FORGED`, exit 1.
- `reconstruct` inherits through `_check`.

## Errors

A sidecar that fails to parse or verify is `FORGED`, not a crash: it is untrusted input like the ledger. A PEM holding a non-Ed25519 key raises `AttestError` at load. `InvalidSignature` maps to `FORGED`.

## Trust boundary

The key is held by the observed process, so attestation proves the ledger has not changed since run end by anyone without the key. It does not prove the process was honest. Sigstore or an external timestamp would move the key out of the process; not in scope.

## Tests

`tests/unit/test_attest.py`, keys generated in `tmp_path`:

- keygen writes both files, key mode 0600, refuses overwrite
- run with signer writes sidecar; verify with pubkey is ATTESTED
- failed run still attested
- truncated tail: FORGED
- forged tail (rewritten `run.end` with matching count, rechained): chain OK, FORGED
- one byte edited inside a line: FORGED via `ledger_sha256`
- wrong pubkey: FORGED
- edited sidecar: FORGED
- no sidecar: UNATTESTED; sidecar without pubkey: UNCHECKED
- `attest` CLI refuses BROKEN ledger and existing sidecar; exit codes via `CliRunner`
